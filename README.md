# IntelliJ IDEA UI Test: Сreate changelists automatically

This project contains an automated UI test for IntelliJ IDEA using the **IDE Starter** framework.

## Scenario
1. Open IntelliJ IDEA with a sample project.
2. Navigate to **Settings** -> **Version Control** -> **Changelists**.
3. Enable the checkbox **"Create changelists automatically"**.
4. Verify that the checkbox is selected.
5. Save changes by clicking **OK**.
